Коллекция плагинов для лампы

Можно подключить в лампу по ссылке на github pages.
https://darknotevil.github.io/lampa-plugins-collection/collections.js


- collections.js - изменяет раздел коллекции на прокручивающийся список избранное + пользовательские коллекции. Убирает чужие коллекции. Добавляет управление коллекцией в карточку фильма. Так же переопределяет пункт меню мои торренты на коллекции для автозапуска
- lme-slim.js - убирает лишние кнопки и эмодзи на карточке фильма, позволяет изменять порядок 
- unblock.js - снимает ограничения категорий (не снимает dmca)
- kinopoisk-okko.js - кнопки «КиноПоиск» и «Okko» в карточке. Нажатие открывает фильм/сериал прямо в Android TV приложении (kpatv://film?filmId=<uuid КП HD>, okko://movie?uid=<uuid>&type=MOVIE|SERIAL), долгое нажатие - сайт. Id ищутся через GraphQL КиноПоиска и JustWatch; если тайтла нет в сервисе, кнопка полупрозрачная. Проверено на ru.kinopoisk.tv 2.265 и tv.okko.androidtv 3.188.
- superplugin.js - подгружает все плагины из репозитория одной ссылкой (не проверялся на ТВ)
- torrents.js - модификация поиска торрентов. Новый фильтр сортировки "качество+раздающие". Убрана левая панель описания. Подсветка качества и раздающих. Пустой фильтр позволяет сделать сброс. Быстрые кнопки качества и сезонов под шапкой, контрастный фокус в меню фильтра.
